# cricket-team-selector
A Python terminal app that randomly selects  Playing 11 from a pool of 15 cricket players  and assigns a random captain.

# Cricket Team Selector 🏏

A fun terminal-based cricket team selector built with Python!

## How it works
- 15 players are in the pool
- Program randomly selects Playing 11
- Remaining 4 go to bench
- Captain is randomly chosen from Playing 11

## Features
- Random team selection every time
- Captain assignment
- Playing 11 display
- Bench players display

## Concepts used
- Random module (shuffle, choice)
- List slicing (players[:11])
- For loop with enumerate
- String formatting
